RIZAL REFLECTION WEBSITE

HOW TO USE
1. Extract this ZIP file into a folder.
2. Open index.html in your browser to preview the website.
3. The group names are in index.html. Find MEMBER 3 and MEMBER 4 and replace them with the correct names.
4. Put the four photos inside the images folder using these exact filenames: coloma.jpg, amplayo.jpg, member3.jpg, member4.jpg.
5. To edit the design, open style.css. To edit the popup/menu behavior, open script.js.

The popup is already connected. Click the group names in the footer to open it.
